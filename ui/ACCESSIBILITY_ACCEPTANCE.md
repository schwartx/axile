## 入口与操作

1. 点击常驻主题按钮，确认浅色、深色、跟随系统下方有分隔线及唯一的「无障碍设置…」入口，无新导航页面。
2. 点击入口，菜单关闭，打开「无障碍设置」居中弹窗，说明为「即时生效，仅保存在当前浏览器」。没有保存、取消、恢复默认按钮。
3. 确认开关是滑块外观，配色是六行紧凑单选列表，左侧小勾、名称与右侧正负样例对齐，没有大卡片边框，预览中的输入边界只是静态样例；没有浏览器原生 checkbox、radio、select 或 dialog 外观。
4. 先用关闭按钮，再分别用遮罩、Escape 关闭；每次确认修改保留，焦点返回常驻主题按钮。
5. 仅用键盘 Tab 到主题按钮、Enter 打开菜单、Tab 到设置入口、Enter 打开弹窗。开关用 Space / Enter；配色用四个方向键、Home / End。确认焦点清晰，Tab / Shift+Tab 保持在弹窗内。
6. 在桌面宽度下确认弹窗为约 820px 横版，左侧设置、右侧独立实时预览，中间细分隔线，没有嵌套预览卡片。改变设置时右侧位置稳定，正文只有一个滚动区域。
7. 在约 320px 宽窄屏重复操作，确认设置在上、预览在下，六个方案仍为纵向列表、名称和样例无挤压溢出、说明文字换行、正文可滚动且无横向溢出。

## 强化方向标记

1. 对五套彩色方案分别关闭／开启「强化方向标记」，确认行情正负文字增加／移除 ↑／↓，零值和未知值不加方向箭头；运行、警告和滑点质量不加涨跌箭头。
2. 确认预览中负向曲线随开关切换为虚线，负向柱形增加斜纹；实际每日盈亏负值柱和负权重条也同步增加斜纹，资金划转柱保持原语义。绩效曲线已有的实线／虚线继续表示账户与组合，不改成涨跌编码。
3. 选择单色，确认正负值使用同一中性色，方向标记始终开启、开关不可关闭，并显示原因；正负值仍可通过符号、箭头、位置和纹理区分。
4. 先关闭标记，再进入单色，再切回彩色，确认恢复关闭；先开启标记，再执行同样操作，确认恢复开启。
5. 方向标记开启时复查窄屏下的权益数字、持仓、多空、净敞口和成交盈亏，没有截断关键信息或产生横向溢出。

## 持久化与异常

1. 设置蓝涨橙跌并开启增强对比度与方向标记，切换页面、切换明暗、刷新，确认偏好一致且首屏无错误配色闪烁。跟随系统时切换系统主题也应保留偏好。
2. 同源打开第二标签页，两边保持弹窗打开；任一页改变开关／配色，另一页的页面、列表和两个开关同步。清除该存储键或清空站点存储后，两页恢复默认。
3. 在开发者工具的站点存储中，将 `axile-accessibility` 分别设为损坏 JSON、`null`、空对象，以及 `{"enhancedContrast":true,"marketPalette":"invalid"}`。刷新后依次确认完整默认、完整默认、完整默认、增强对比度开启且红涨绿跌。反向测试一个非法对比度字段搭配合法配色，应仅回退对比度字段。
4. 禁用站点存储或模拟存储写入失败后刷新。确认仍可打开设置，说明变为「当前浏览器无法保存，刷新后恢复默认」，修改在会话中即时生效，刷新恢复默认。
5. 分别对蓝涨橙跌、红涨青跌、单色执行刷新与跨标签同步，确认首屏 class、列表选中行和方向标记一致。旧版仅含对比度与配色的存储应保留原偏好并默认关闭方向标记；非法 `directionMarkers` 值单独回退为关闭。
6. 恢复存储权限，关闭增强对比度、关闭方向标记并选择红涨绿跌，确认恢复默认显示效果。
