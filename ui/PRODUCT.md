# Axile 管理界面

## Platform

Web。操作者通过浏览器管理账户、组合及交易执行。

## 回放的用途

选择一次已有执行，观察当时的盘口、报撤单和成交过程。以 Bookmap 的同屏操作方式为参照，图表、盘口、订单和播放控制共享一个游标；播放、暂停、调速和定位不需要上下滚动页面。

回放只读，读取录制不会连接账户、补发查询或触发交易。只能展示实际观察到的事实；未知、过期、缺失和账户上下文不能冒充本次执行的完整数据。

## 已确认的交互方向

采用「盘口工作台」：大幅盘口热力图横向铺开，占据工作区主要高度；图中呈现实际市场成交价轨迹、成交圆点及自有委托线，右侧盘口量与自有量共用价格轴。订单列表和选中记录的两行摘要放在底部，完整字段按需打开。播放、步进、倍速与时间轴始终留在底部，读取窗口和录制段选择收进录制信息。验收以桌面为准，不扩展手机适配。

默认优先选中当前游标已观察到的本次委托；方向、价格、数量和状态在底部摘要显示；原生字段和身份在完整记录中查看。「聚焦委托」只平移价格轴，保留真实价差和价格尺度。

## Stack

React、TypeScript、Tailwind CSS 和 Canvas。设计语义沿用 `src/styles/theme.css` 与仓库 `axon-frontend-language` 技能；不添加另一套颜色或动效系统。

回放的页头和控件复用现有 `AccountPageTitle`、`Select`、`ValueSlider`；品种在图表工具栏内切换，单一品种不显示无作用的下拉。
