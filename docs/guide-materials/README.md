这是一套供 GitHub Pages 使用文档编排的素材稿，按「认识 → 启动 → 第一个组合 → 目标换算 → 自定义函数 → 日常运行 → 排错 → 参考」组织。读者默认理解多空、权重、持仓与调仓；Python 接口从最小例子开始讲。

42 张原图已移至 `../site/assets/screenshots/`，本目录只保留说明、示例和采集记录，不保存图片副本。`manifest.json` 中的图片路径相对本目录。

采集日期：2026-10-12。基线：Axile **0.19.1**，源码提交 `1f89098e251187ba44b1c6f909709f434b973f50`。共 **42 张原始 PNG 截图**，统一为浅色主题、1440 × 1000 CSS 像素，未修改截图中的界面或业务数据文本。

> **数据来源**：账户、价格、持仓、订单和成交均为离线教学夹具。运行的是独立安装的 Axile 公共版；天勤执行器工厂在专用进程中替换为离线替身，未连接天勤或真实交易账户。真实 UI、函数运行、API、数据库、审计与展示逻辑照常运行。图中的收益、滑点和执行耗时不构成算法测试结果。详见 [环境与复现](support/README.md)。

## 贯穿全站的例子

- 组合：**双品种目标 · 离线演示**，函数返回 `{"rb2701": 0.4, "ag2612": -0.25}`。
- 账户：**期货教学账户 · 离线演示**，权益 100 万元，多空杠杆均为 1。
- 教学价格：rb2701 为 3,200 元、乘数 10；ag2612 为 8,000 元、乘数 15。
- 起始持仓：rb2701 多 6 手，ag2612 空 1 手；可执行目标为多 12 手、空 2 手。
- 演示顺序：完整成交 → 无需调仓 → 重置离线起始持仓、演示部分成交 → 补齐剩余缺口。
- 所有合约代码、价格和控制参数仅用于讲解界面，使用者须按当前渠道、合约和账户配置替换。

## 编排建议

每个操作小节使用「要完成的事 → 操作 → 截图 → 预期结果」的结构。尽量一张图只解释一个问题。先用 03 跑通，再解释 04 的数量和 05 的函数；把字段大全、完整 executor 和算法开发放到 08。

原图保留完整页面，正式排版时可以再按主题裁切或添加编号标注。章节 README 中的图说可作为正文起稿。素材已整理为 [VitePress 文档站](../README.md)，正文位于 `docs/site/`。Pages 工作流在 PR 上只构建，合并后按部署说明发布。
