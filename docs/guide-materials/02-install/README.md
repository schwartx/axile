# 02 · 安装与启动

目标：第一次打开 Axile，完成初始化并进入控制台。

![第一次启动](01-first-start.png)

图说：首次启动进入初始化向导。系统执行告警为选填项；未配置 Webhook 时不会推送消息。这里可以先继续，再到系统告警页面配置。

| 顺序 | 图片 | 操作与预期结果 |
| --- | --- | --- |
| 1 | [首次启动](01-first-start.png) | 选择告警方式；本次留空，不发送外部消息 |
| 2 | [确认初始化](02-confirm.png) | 核对设置，保存配置 |
| 3 | [高级选项](03-advanced.png) | 了解数据库、环境、日志和用户算法目录，一般沿用默认值 |
| 4 | [空控制台](04-empty-console.png) | 服务正常、尚无账户，开始创建组合和账户 |

供正文使用的源码安装步骤（在独立的 Axile 仓库根目录运行）：

```bash
uv sync --extra tqsdk
cd ui
bun install
bun run build
cd ..
uv run axile --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000`。需要 CTP 或掘金时，应根据渠道与平台安装对应 extra；截图中的 CTP、掘金暂不可用，表示本次环境没有安装这些可选依赖，并不代表公共版没有这些渠道。

当前初始化以配置文件是否存在判断是否完成，不需要填写旧版的量化数据 API 或 Token。`local`、`staging`、`production` 控制日志详细程度；实盘、快期模拟、本地模拟在账户连接中选择。

**启动行为需要写清楚**：向导保存配置后会结束当前服务进程，让外部 supervisor 重新拉起。裸命令启动时，需要再次执行启动命令；本次采集也进行了第二次启动。不能承诺裸 CLI 会自动重启。对应源码：`axile/server/api/routes/init.py::_restart_process`。

本次素材实际使用独立环境、临时数据库和 8019 端口，详见 [复现说明](../support/README.md)。
