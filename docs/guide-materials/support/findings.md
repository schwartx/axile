## 内置开发文档直接打开返回 404

复现：打开 `http://127.0.0.1:8019/docs/custom-calc`，返回 `{"detail":"Not Found"}`。组合编辑器“开发文档”也会在新页打开该地址，因此同样受影响。

源码依据：`axile/server/app.py` 将 `docs` 作为保留路径前缀，SPA fallback 会拒绝 `/docs/*`。真实前端确有 `/docs/custom-calc`、`/docs/notification` 等路由。

本次参考截图的采集办法：先打开能正常托管的组合编辑器，再通过 History API 切换到现有 React Router 路由并派发 popstate。页面由原有 React 组件渲染，没有注入或改写界面内容。这是采集绕行，不是对用户可用性的修复。

正式教程发布前应处理路由冲突，或者把相关内容放到 GitHub Pages 后直接链接文档站。

## 裸 CLI 的初始化保存不会自动重启

初始化保存会向自身发送 SIGTERM，由外部 supervisor 拉起。裸 `axile` CLI 没有 supervisor。本次首次保存后，重新运行 CLI 完成启动。

向导文字写“自动重启”，正文需要说明运行方式与实际行为；启动教程不应承诺裸命令能自行重启。
