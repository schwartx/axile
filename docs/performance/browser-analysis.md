# 浏览器本地分析

实盘绩效页的成本筛选、滑点分布和未保存费率试算，以及回放页的区间统计，使用 Web Worker 内的 WASM。收益引擎与成交成本口径来自 `rust/analysis-core`，原生存储复用同一实现。

## 数据的归属

| 数据或结果 | 生命周期 |
| --- | --- |
| 成交、执行输入、目标快照、合约乘数、原币手续费 | 后端规范事实，继续保存 |
| 正式收益及品种贡献、增量游标和持仓状态 | 后端五张分析表，继续增量更新 |
| 浏览器成本筛选、分布、费率试算和回放区间统计 | 当前页面内存，切换窗口或离开页面时释放 |
| 点击“保存并计算”后的费率 | 现有设置 API 保存，后端重算正式成果 |

试算不改账户收益、正式品种贡献、下单参数或执行审计，也不写浏览器持久存储。页面明确标出未保存试算；取消后恢复正式回测曲线。

## 完整性和边界

`GET /api/v1/account/analysis/{account_id}/inputs` 绑定 `version`、`range`、`kind`、选区（`day`、`start/end`、`record_id`）和不透明游标。每页最多 100 条记录、约 2 MiB；单次执行超过 20,000 笔成交时拒绝本地加载。每一页都重新检查源版本，版本变化返回 409。只提供归一化观测和必要成交字段，不回传原始执行输入或结果。

成本分析默认折叠，不加载成本输入或启动成本 Worker；展开后只加载当前图表选区的成交，未选中时加载当前 30/90 天或全部范围。同一选区收起再展开复用已加载数据；更换账户、版本、范围或选区会取消旧请求并清空旧结果。品种与方向筛选复用当前选区输入，不再请求服务器。折叠时区间摘要仍使用轻量后端汇总。

成本响应中的 `records[].trades` 使用现有 `{columns, rows}` 表格格式，客户端解码后交给 WASM；不省略未知值、费用币种或估算时间标记。筛选按成交时间而非执行创建时间裁剪，缺少成交时间时沿用执行时间。分页游标绑定选区，不能跨选区复用。

输入协议版本为 2：默认 `kind=costs` 只读取成本事实，不读取收益重放观测；修改费率后才按需请求 `kind=fees`。两类游标不能混用，加载预算分别计算。成本和试算使用独立 Worker，当前版本和范围内最多缓存四个费率结果，切换成本选区不会重放收益。费率输入禁止选区参数，以免用局部事实试算整条曲线。

客户端完整加载后才发布输入：最多 16 MiB、20,000 条记录、150,000 笔成交。超限或 WASM 不可用会显示原因，正式绩效和后端明细仍可用；区间成本汇总回退到现有后端接口。Worker 最多保留一个运行请求和一个最新待处理请求；旧窗口或旧选区结果不能覆盖当前结果。

- 成本时间区间为 **(起点, 终点]**，与后端成本查询一致。缺少价格、参考价、乘数和费用时保留未知；原币费用分开汇总。
- 费率试算使用完整窗口的原冻结目标和定价证据，复用数量目标、换算、缺价跳过、清仓及上海日界规则。没有有效权益基线时不虚构本金。
- 回放区间为 **[起点, 终点)**，包含已加载的游标后记录时显式提示。盘口只统计有效区间，不跨录制段、过期或缺口延展；挂量未知、不足 N 档或双边总量为零时不计算不平衡。
- 市场成交和账户成交分开计算，按录制段和稳定成交身份合并各窗的完整投影事实，再按时间筛选；迟到补全、更正和冲突不因绘图裁剪丢失，已升级为稳定身份的弱观察不重复计数。只纳入身份稳定、无冲突且价格和数量有效的记录。缺少市场成交流时不以账户成交或 tick 累计量替代。来源、缺口和价格单位只按与当前选区相交的录制段判断；选区外的旧元数据不影响结果。价格分布按录制的最小变动单位分桶，最多 128 桶；缺少一致单位时只提供 VWAP 和成交量。

## 构建与验证

沿用 `ui/scripts/build-replay-heat.ts` 和现有 WASM 产物，无额外运行时依赖。`bun run build` 会构建 WASM、检查类型并打包 Worker/WASM 静态资源。Rust target 应放在源码树外，使用固定工具链和 `--locked`。

定向检查覆盖原有收益重放回归、原生分页与版本失效、WASM 与独立 JS 成本口径对照、未知深度、成交身份和 Worker 过期响应。前端交互需使用隔离数据库验收；真实账户与实盘执行不属于此功能的验证范围。

## 带宽实测（2026-11-14）

同一份 400 次执行、40,000 笔成交、8 个品种的合成数据库，比较修改前后生产 API 与 Worker。下表是曲线与成本输入流程的压缩响应体，包含曲线、排除不变的账户/状态读取、HTTP 头和静态资源；每项 3 轮取中位数。耗时使用 Chromium 模拟 2 Mbps 下载、80 ms 延迟，Worker/WASM HTTP 缓存已热，不含图表绘制。

| 场景 | 改前 API 响应体 | 改后 API 响应体 | 改前耗时 | 改后耗时 |
| --- | ---: | ---: | ---: | ---: |
| 首载，成本分析未展开 | 381.0 KB | 17.6 KB | 2.658 秒 | 0.247 秒 |
| 查看一天（400 笔成交） | 381.0 KB | 21.6 KB | 2.668 秒 | 0.369 秒 |
| 查看一次执行（100 笔成交） | 381.0 KB | 18.9 KB | 2.653 秒 | 0.351 秒 |
| 查看一周（2,800 笔成交） | 381.0 KB | 42.9 KB | 2.648 秒 | 0.475 秒 |
| 查看全部范围 | 381.0 KB | 283.5 KB | 2.669 秒 | 2.103 秒 |

KB 按 1,000 字节计。单天成本输入本身为 4,027 字节，其余主要是曲线；同一选区内 20 次品种/方向筛选均没有 API 传输。大样本本机首载 API 进程 CPU 中位数从 795.7 ms 降到 128.2 ms，单天流程从 794.2 ms 降到 153.3 ms，包含原生读取和压缩，未运行交易或调度。

小样本（2,000 笔）整窗首算在本机从约 63 ms 增至 99 ms，响应体仅减少约 8%；限速场景约 304→295 ms。收益主要来自按需加载和范围裁剪，不能保证所有小窗口都算得更快。未选中任何子范围而直接展开时，仍需完整加载当前 30/90 天或全部范围。

WASM 静态资源另计，首次展开可能需要下载约 432 KB，浏览器缓存后复用；主表不是新浏览器全冷首访耗时。以上均为本机合成数据和模拟网络，未作真实公网或生产账户负载验收。
