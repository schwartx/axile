# 浏览器本地分析

实盘绩效页的成本筛选、滑点分布和未保存费率试算，以及回放页的区间统计，使用 Web Worker 内的 WASM。收益引擎与成交成本口径来自 `rust/analysis-core`，原生存储复用同一实现。

## 数据的归属

| 数据或结果 | 生命周期 |
| --- | --- |
| 成交、执行输入、目标快照、合约乘数、原币手续费 | 后端规范事实，继续保存 |
| 正式收益及品种贡献、增量游标和持仓状态 | 后端五张分析表，继续增量更新 |
| 浏览器成本筛选、分布、费率试算和回放区间统计 | 当前页面内存，切换窗口或离开页面时释放 |
| 点击“保存并计算”后的费率 | 现有设置 API 保存，后端重算正式成果 |

试算不改账户收益、正式品种贡献、下单参数或执行审计，也不写浏览器持久存储。页面明确标出未保存试算；取消后恢复正式回测曲线。

## 完整性和边界

`GET /api/v1/account/analysis/{account_id}/inputs` 绑定 `version`、`range`、`kind` 和不透明游标。每页最多 100 条记录、约 2 MiB；单次执行超过 20,000 笔成交时拒绝本地加载。每一页都重新检查源版本，版本变化返回 409。只提供归一化观测和必要成交字段，不回传原始执行输入或结果。

输入协议版本为 2：默认 `kind=costs` 只读取成本事实，不读取收益重放观测；修改费率后才按需请求 `kind=fees`。两类游标不能混用，加载预算分别计算。成本和试算使用独立 Worker，当前版本和范围内最多缓存四个费率结果，切换成本选区不会重放收益。

客户端完整加载后才发布输入：最多 16 MiB、20,000 条记录、150,000 笔成交。超限或 WASM 不可用会显示原因，正式绩效和后端明细仍可用；区间成本汇总回退到现有后端接口。Worker 最多保留一个运行请求和一个最新待处理请求；旧窗口或旧选区结果不能覆盖当前结果。

- 成本时间区间为 **(起点, 终点]**，与后端成本查询一致。缺少价格、参考价、乘数和费用时保留未知；原币费用分开汇总。
- 费率试算使用完整窗口的原冻结目标和定价证据，复用数量目标、换算、缺价跳过、清仓及上海日界规则。没有有效权益基线时不虚构本金。
- 回放区间为 **[起点, 终点)**，包含已加载的游标后记录时显式提示。盘口只统计有效区间，不跨录制段、过期或缺口延展；挂量未知、不足 N 档或双边总量为零时不计算不平衡。
- 市场成交和账户成交分开计算，按录制段和稳定成交身份合并各窗的完整投影事实，再按时间筛选；迟到补全、更正和冲突不因绘图裁剪丢失，已升级为稳定身份的弱观察不重复计数。只纳入身份稳定、无冲突且价格和数量有效的记录。缺少市场成交流时不以账户成交或 tick 累计量替代。来源、缺口和价格单位只按与当前选区相交的录制段判断；选区外的旧元数据不影响结果。价格分布按录制的最小变动单位分桶，最多 128 桶；缺少一致单位时只提供 VWAP 和成交量。

## 构建与验证

沿用 `ui/scripts/build-replay-heat.ts` 和现有 WASM 产物，无额外运行时依赖。`bun run build` 会构建 WASM、检查类型并打包 Worker/WASM 静态资源。Rust target 应放在源码树外，使用固定工具链和 `--locked`。

定向检查覆盖原有收益重放回归、原生分页与版本失效、WASM 与独立 JS 成本口径对照、未知深度、成交身份和 Worker 过期响应。前端交互需使用隔离数据库验收；真实账户与实盘执行不属于此功能的验证范围。
