# 执行日记先分页再读取详情

基线为 Axile main `d90ba7a`，包含前两次已验收优化。生产改动仅在 `account_schedule.py`：

- 将执行与休市记录的时间、ID、类型合并，在 SQLite 中确定当前页。
- 仅载入当前页的详情；执行记录不读取摘要计算未使用的 `raw_input`。
- 保留原 `project_execution`、`summarize` 及字段转换，未修改计算公式或 JSON 存储格式。
- 排序仍为时间倒序、ID 倒序；两表时间和 ID 相同时，执行记录优先。总数、时间窗左闭右开、分页参数、返回字段均保持不变。
- 用 SAVEPOINT 让总数、页头、详情共享同一 SQLite 读快照，避免并发删除导致详情缺行；不提交或回滚调用者原有事务。

前端 `loadJournal` 每页请求 500 条直到读完时间窗。原实现每次重新读取、解析、计算前 `skip + limit` 条；读取 10 页会处理 55 页的执行载荷。现在只解析实际返回页；标量查询的 OFFSET 扫描和排序仍然存在，不宣称所有数据库工作变为线性。未改前端或账户当日委托/成交接口，品种汇总接口也不在本次范围。

## 对照方法

同一 macOS / Python 3.12.12 / SQLite 3.50.4 / SQLAlchemy 2.0.52 环境，原版与候选交替各三轮，每轮全新进程和独立可写数据库副本。完整导入应用，以真实 FastAPI 路由、中间件和 ASGI HTTP 请求执行读取、原摘要计算及序列化。既读取全部历史，也读取固定时间窗；按前端方式连续读取所有页面，检查总数、重复与缺行。所有响应状态、完整 body 的长度与 SHA256 逐项一致，不剔除任何字段。

耗时为整组 HTTP 请求从开始到结束；进程峰值包含完整应用导入，取系统 `ru_maxrss`；稳定 RSS 为请求完成后 1 秒内采样的中位数。另用同一解码包装统计实际交给 Python JSON 反序列化器的字节数。OS 文件缓存为热缓存，不强制 GC。不启动交易和调度生命周期，禁止出站连接；不能将本报告外推为线上完整服务常驻内存的结论。

## 数据和结果

真实 CHEN 封存副本保持全部原始内容，26 条执行，其中 23 条输入非空，另有 2 条原始休市记录。未清空 `raw_input`，也未重新计算或生成冻结绩效快照。源文件 SHA256：

`27745d4b7722e5c5769ca56d9f502503503b0eba4edd0cefd6f7e0dbd7222a99`

规模案例由本次脚本直接从该封存副本生成：保留全部原始表和记录，循环复制完整执行输入、结果的原始 SQLite 文本，仅改变新记录的 ID、execution_id 和发生时间，扩到 2,000 条执行。每五条新增执行插入一条同时间、同 ID 的合成休市记录，新增 395 条休市，与原有 2 条合计 397 条，检验跨表排序和分页。**这些是合成重复负载，不是真实 2,000 次交易，不是四渠道历史覆盖。** 两组使用同一生成文件，其 SHA256：

`d710564ade4c08e5f4e5f3b48af2d8a6a723eb63338de6c01a0adf6a4bbf048e`

三轮中位数：

| 指标 | 真实 CHEN 原版 | 真实 CHEN 候选 | 混合规模原版 | 混合规模候选 |
|---|---:|---:|---:|---:|
| 每轮 HTTP 请求数 | 2 | 2 | 10 | 10 |
| 全部请求耗时，秒 | 0.3886 | 0.3851 | 1.6657 | 0.7577 |
| 整进程峰值，MiB | 198.42 | 198.22 | 278.86 | 215.19 |
| 请求后稳定 RSS，MiB | 198.41 | 198.20 | 278.84 | 215.17 |
| SQLite 交给 Python 解码的 JSON 合计，MiB | 0.145 | 0.120 | 72.211 | 16.742 |

混合规模浏览耗时减少约 55%，峰值与稳定占用减少约 64 MiB（23%）。真实小样本基本持平，不能宣称小数据也有显著收益。

另外对已有的完整 CHEN 载荷 2,000 条合成副本（无休市）各三轮对照：8 次请求耗时 1.2738 → 0.7339 秒，峰值 277.64 → 217.64 MiB，HTTP body 同样完全一致。未将该案例冒充独立真实历史。

## 其他验收

相关核心测试 46 项通过，匹配 Axon main `7bbf3a25` 的发行层 160 项通过、1 项跳过；Ruff、C901≤15、修改生产文件的 BasedPyright 通过。新增回归实测：

- 同时间同 ID 的执行/休市混排、连续页与尾页、账户隔离、空匹配及时间边界；摘要逐字段保持原投影结果。
- 深页只计算当前页两条记录，2 MiB 的无关执行输入不进入 JSON 解码器。
- WAL 并发删除发生在总数读取后，当前请求仍完整返回原快照；新会话可见删除结果。
- 请求结束不提交调用者的待提交修改。

未修改前端契约或页面交互。本次验收使用完整 HTTP 响应对照；没有部署或操作线上数据。
