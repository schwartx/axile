# 后端增量分析

当前实现见 [五表模型设计](../design/native-incremental-analysis.md)。Rust 直接读规范事实，普通追加推进当前状态，日结果与游标原子提交；历史修订、删除、同刻替换和迟到记录安全重放。

空库和已发布 `0033` 的升级均直接生成最终 `0034` 结构，不经过开发期的旧分析表。`0032` 及更早版本须先安装 `v0.23.1` 并升级到 `0033`。迁移和运行时分析使用同一版本的 Rust 原生扩展。

查询入口是 `/api/v1/account/analysis/{account_id}`，状态在 `/status`，成本在 `/costs`，单次详情在 `/execution/{record_id}`。除状态外均要求十进制字符串 `version`；事实或结果变化返回 409。前端保留已经显示的完整结果，并重新读取状态和新版图表。

`test_incremental_analysis.py` 用实际迁移、业务阶段写入和独立全量回放验证日内/跨日追加、滚动基线、重启、修订删除、失效领取及写入回滚。`test_native_analysis_regressions.py` 验证微秒边界、跨日成交成本、缺失金额和零费用；品种贡献用真实持仓和平仓事实验证。旧快照发布、复制和查询基准脚本随旧实现删除；此前的性能数字不代表五表模型。
