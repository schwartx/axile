# 原始回放：区间、恢复与传送验收

2026-11-15，本地 `codex/replay-single-source` 工作树。沿用已有真实录制和 40,000 身份样本，未增加长测规模，未部署。原始 MCAP 使用 v2，传送包使用格式 2；没有加入旧格式读取或旧引擎对照。

2026-11-16 补充：后续提案对照审查发现并修复的语义、页面及资源规划问题，连同复验数据，见 [提案对照复审](raw-replay-proposal-review.md)。本文保留首次交付的历史验收记录。

## 本次交付

- 完整区间输入先规划，再在 Worker/WASM 归约。观察截止点与 `[S,E)` 分开；显式关联后的稳定身份沿用其原始观察时间，弱身份、冲突及未知归属单独报告。
- 自有与市场分别计算数量、金额、VWAP。价格分布只在请求时执行第二遍，使用第一遍的全局 tick 原点及统一宽度，最多 128 桶；两遍证据指纹不同则拒绝结果，第二遍不重复累计成交金额。
- 报价从 S 前的最后观察开始积分，按有效期、采集边界和连接状态裁剪。价差与不平衡各有有效时长。没有采集或期限证明时保留未知，不把它变成零或完整覆盖。
- 增加必要的市场身份和关联位置索引，共同命名空间只保存一次；服务端仍不保存业务状态、成交聚合或价格分布。
- 派生状态按源视图、索引代次、品种、窗口、参数、求值范围与修订管理。恢复点与结果各有容量限制；正常根任务结算、计划重新生成或读取实例变化不会自行使相同计算上下文失效。
- 晚到关联指向已越过的前史时，使相关范围的恢复点失效，保守重建一次；同根任务最多 8 次扩大，重复遗漏报告契约错误。按相关源/品种范围保守失效，其他独立基础上下文保留；不保存全历史反向依赖图。
- 索引换代后重新解析流 ID，丢弃旧派生状态和旧分页游标，保留校验一致的压缩块。结果携带实际索引代次，下一页游标携带来源代次；后续目标复用已解析目录，不反复进行同一恢复。重试仍属于原逻辑根任务，最多 3 次尝试，累计成本和原期限不清零。
- 传送导出固定提交的原始前缀，包含重建所需上下文、流和提交记录。显式 `content_refs` 递归补齐依赖前缀；`previous_recording_id` 只表示顺序。
- 包内不携带可直接安装的回放索引。导入先验证原始文件，再重建本地索引；同源前缀只能延长，重复导入不缩短原始数据、不无故更换已有索引代次。未完成的索引安装有独立标记，可重试完成。
- 浏览器通过准备后的 GET 下载包，不用 JavaScript Blob 缓冲整个数据包。新增暂存包取消入口；取消只删暂存副本。已有导入、确认、来源约束及暂停调度规则继续由原传送链路执行。

## 资源与终止规则

| 范围 | 上限或规则 |
| --- | --- |
| 单点根任务 | 8 MiB 逻辑计费、8,000,000 索引工作单位、60 秒 |
| 区间根任务 | 128 MiB 逻辑计费、16,000,000 索引工作单位、120 秒；两遍、规划和重试共用 |
| 账户速率 | 32 MiB、2,000,000 索引工作单位；10 秒窗口加 1 秒保守边界 |
| 单次 SQLite | 200,000 工作单位、2 秒；不长时间持有读事务 |
| 数据并发 | 全局 4、账户 2、根任务 1；发送停止后才释放 |
| 会话 | 最多 64，单账户最多 4；租期 90 秒，正常每 30 秒续期 |
| 控制调用 | 单账户 256 次 / 2 秒 |
| 读取文件租约 | 单根最多 64，全局最多 128；保护正在使用的原始录制 |
| WASM | 链接硬上限 32 MiB；每 16 个事件让出执行，单 RPC 看门狗 5 秒 |
| 压缩缓存 | 载荷 4 MiB、4096 项、键最多 256 字符；键和 Map 另有有界开销 |
| 派生缓存 | Worker 恢复点最多 8 项 / 1 MiB；主线程结果最多 8 项 / 1 MiB |
| 当前批次 | 16 个流头；传输 1 MiB / 128 块；依赖 128 个身份，展示 8 个对象 |
| 状态和输出 | 宽批次保留状态、业务输出各 256 KiB，超限在同根任务内拆小 |
| 待传包 | 最多 4 个，总量最多 4 GiB；单包及解压文件总量最多 4 GiB |

字节计费包含原始载荷、二进制封装、索引响应及定位编码读取；它不等同于操作系统的物理磁盘读取量。SQLite 工作单位用于限制索引查询成本。会话及账户累计值跨播放段保留。

主线程只有一个运行目标和一个最新候选。取消后先停止 Worker、HTTP 和服务端实际作业，再封口及 ACK；旧尝试、旧根序号、旧读取实例和旧索引代次均不能重新取数。缓存保留的内存继续记账。

每个数据响应提供成本水位。最终回执替换预留，重复 ACK 不再累计。读取实例重启后，必须用原会话签名及文件所有权锁证明旧作业停止；普通未知 UUID 不能当作停止证明。新实例立即接收读取，进程内速率桶重新计量；正常运行时新建会话不能重置账户限流。原根任务带剩余预算与已用时间恢复，缺失尾部按单次预留上界结算并标记估计，不能记为零。

只有整份、已关闭、超过保留期、完整接收确认且原始哈希仍匹配的录制才能清理。内容引用、读租约、导出准备及活动写入会阻止或延后删除。清理使用删除临时文件和索引事务；重试和索引重建须区分事务尚未提交与已提交的情况，保留被引用的数据，不因重建遗漏原始文件。没有块级修剪或自动轮换。

40,000 身份三段任务的会话累计计费为 5,104,152 → 9,215,811 → 12,377,344 B，三段原始读取合计 2,246,521 B。归属、订单剩余量、持仓及未知可用量均按独立期望断言；没有靠新建会话清零累计成本。

真实录制共 4,820,994 条观察。本次主用 `1000SHIBUSDT` 的 50,670 个市场稳定身份，数量 5,100,944,031、金额 21,674,005.064989、VWAP 0.004249018403901205，与独立原始扫描一致。分布原点 4117 tick、宽度 2 tick、122 个非空桶，每桶数量也独立核对。报价流及两遍市场流的压缩载荷下界为 60,447,325 B，实际原始读取为该下界的约 1.0046 倍；下界尚未包含自有业务前缀和预览开销。

这份离线原始样本没有完整采集边界证明，报价覆盖为未知、均值为 null，市场完整性为 false；没有将数量正确误报为覆盖完整。小型契约样本另验证严格区间边界、S 前报价、有效期裁剪、迟到弱身份解析、全局分桶和反向恢复。

统一运行中 WASM 最大 3,276,800 B，压缩载荷缓存始终不超过 4 MiB，服务端峰值 RSS 150,470,656 B，结束时活动读取为 0。结束时主线程堆约 3.36 MB。上述数值不把整个浏览器进程 RSS 当成硬上限；硬限制覆盖 WASM 和应用管理的缓存、页、槽位及在途缓冲。

实际故障用例在服务器已生成响应、浏览器尚未消费响应时重启服务。逻辑任务 6 以尝试 2、新传输根 1 恢复，等待 11.08 秒；保留 1,052,515 B 根成本和 201,064 索引工作单位，最终累计 1,102,515 B，明确标记估计。没有把估计作为正常资源收益。

101 项定向 Python 检查、32 项 Rust 纯归约测试、3 项传送边界测试、3 项 WASM 边界测试、11 项客户端测试（119 个断言），以及类型检查、Ruff 和生产构建通过。真实浏览器统一用例覆盖区间、反向跳转、缓存复用、实际读取实例重启，以及既有大身份订单/持仓/统计；最后补丁针对长身份预览、清理重建、冻结时点流目录和换代后分页另做定向验证。长身份只在预览中截断并标记，实际 WASM 另断言业务身份完整保留。
