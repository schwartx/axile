# Python 编辑器

组合函数、账户通知、系统通知和初始化向导共用 Python 编辑器。连接 Axile 时，补全、悬停、签名、类型诊断、引用和源码跳转由服务端的 ty 提供。分析使用启动 Axile 的 Python 环境，可以解析这个环境里额外安装的依赖。跳转结果会附带只读源码，支持当前环境中的 editable 安装包。格式化由服务端 Ruff 处理，入口契约检查由 Axile 处理。

打开联网编辑器时，浏览器会把当前编辑内容发给 Axile 做分析。连接中断时可以继续编辑，重连后自动恢复代码辅助。

代码也会保存到浏览器的 IndexedDB。点击状态栏里的“本地草稿”，确认页面显示“可离线使用”后，可断网重新打开、编辑和下载草稿。本地草稿页只在浏览器内编辑，返回原页面即可使用代码辅助、格式化、试跑或提交。

本地开发时用 ego-browser 或 agent-browser 验证在线编辑器，以及生产构建的断网打开和草稿恢复。
