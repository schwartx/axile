# 截图与演示数据

本站使用 2026-10-12 采集的 **42 张原始截图**，对应 Axile 0.19.1。截图由 ego-browser 操作公共版 Axile 页面生成，浅色主题，尺寸 1440 × 1000，可以点击或用键盘放大查看。

## 数据是什么来源

账户、价格、持仓、订单和成交全部为离线教学夹具。采集使用独立的公共 Axile 环境，专用进程中的天勤执行器工厂被替换为离线数据替身，没有连接天勤或真实交易账户。

管理界面、组合函数运行、API、数据库、执行审计与页面展示采用原有公共核心代码。完整成交、部分成交等结果由夹具构造；没有运行真实下单算法循环。

| 项目 | 贯穿例子 |
| --- | --- |
| 账户权益 | 1,000,000 元 |
| 原始目标 | rb2701 为 0.4，ag2612 为 -0.25 |
| 多空杠杆 | 均为 1 |
| 教学价格与乘数 | rb2701 为 3,200 × 10；ag2612 为 8,000 × 15 |
| 起始持仓 | rb2701 多 6 手，ag2612 空 1 手 |
| 可执行目标 | rb2701 多 12 手，ag2612 空 2 手 |

## 怎样理解示例结果

完整成交、无需调仓、部分成交和撤单截图用于说明界面与证据结构。零收益、零滑点和 0.8 秒等数字都是演示输入，不构成执行算法或策略表现的验证。

`offline-docs-main` 和截图中的密码是无效演示字符串，不能照抄来连接渠道。合约代码和教学价格也要根据实际账户与当前行情替换。

## 已知的界面差异

采集基线中，内嵌服务直接打开 `/docs/custom-calc` 返回 404；内置函数说明的截图通过已加载前端的现有路由渲染取得。可直接使用本站的 [Context 参考](/reference/context)。

初始化向导保存会结束进程，裸 CLI 需要再次启动。详见[安装指南](/guide/install#完成首次初始化)。

账户概览曾显示“未记录成交”，但执行详情与记录列表保留了订单和成交。本次只记录了现象，未完成根因分析。核对成交时应继续查看执行详情中的证据。
