# 账户出入金

账户概览的「出入金」区域可录入、修改、撤销资金流水。只填方向、正数金额、实际发生时间和可选备注；币种继承账户渠道配置，不接受逐笔选择币种。页面时间统一显示北京时间，HTTP 写入必须提供带时区的时间。

本功能记录已经发生的资金变动，不执行银行或交易账户转账。

## 渠道同步

目前 CTP 声明支持银期流水查询。已连接账户在刷新资产时自动同步，也可点击「同步渠道流水」。同步复用已有 worker，不自动登录，不创建交易执行；与资产刷新、执行及目标计算互斥。TQ、GM 及未声明能力的插件保留手工录入。

CTP 仅保存方向、金额、发生时间、稳定流水号及撤销标志，不保存银行账号、密码或完整柜台响应。银行端和期货端发起的转账都按方向转换；失败记录不计入，被冲正的已同步记录撤销。接口提供的历史查询范围取决于柜台，不能保证补齐离线期间或更早历史。

渠道流水按账户和流水号去重。与有效手工记录同方向、同金额的渠道流水先进入「待核对」，不重复计入。用户选择对应手工记录并关联，或确认是另一笔；关联后保留手工记录并标为已撤销。已有有效渠道流水时，再录入或修改为同方向、同金额的手工记录，也会进入待核对。修改和撤销保留旧值，撤销的渠道流水再次同步也不会恢复。

CTP 字段依据安装的 OpenCTP SDK，并核对了 [银期流水响应](https://documentation.help/CTP-API-cn/ONRSPQRYTRANSFERSERIAL.html)、[银行端入金](https://documentation.help/CTP-API-cn/ONRTNFROMBANKTOFUTUREBYBANK.html)及[银行端出金](https://documentation.help/CTP-API-cn/ONRTNFROMFUTURETOBANKBYBANK.html)的归档 API 文档。代码与协议测试不代表真实柜台验收。

## 收益口径

原始账户权益不变。账户收益曲线、卡片日涨跌，以及品种贡献中的投资盈亏和未归因差额，剔除已录入的净入金。组合回测保持原有口径。

由于没有每笔出入金前的独立估值，含资金流的观测区间使用 Modified Dietz 近似，再将区间收益复利连接：

`区间收益 = (期末权益 - 期初权益 - 净入金) / (期初权益 + Σ(资金流 × 剩余时间占比))`

入金取正、出金取负。资金流只计入 `(期初观测时间, 期末观测时间]`，基准之前的流水不重复扣除。页面明确标注资金占用时间加权估算及待核对流水；缺少可靠资产或资本分母无效时不编造收益。没有相关资金流的区间保留原有计算结果。

例：权益从 100 增至 150，其中观测末时点入金 50，收益为 0%；随后权益增至 165 且无资金流，累计收益为 10%。

补录、修订、核对和撤销在同一事务中更新分析源版本并请求重算。分析版本仍由现有队列控制，旧计算不能发布为新版本。资金流没有完整录入时，不能保证历史收益准确。

## 存储与接口

公共迁移头为 `0037`，新增账户流水和修订记录表。`0036` 可直接升级；空流水表可降级，有任何流水（含已撤销记录）时拒绝有损降级。

以下路径均相对 `/api/v1/account/{account_id}`：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/cash-flows?limit=20&offset=0` | 分页读取，待核对优先 |
| POST | `/cash-flows` | 手工录入 |
| PATCH | `/cash-flows/{id}` | 修改手工记录，携带 `revision` |
| POST | `/cash-flows/{id}/void` | 撤销，携带 `revision` |
| POST | `/cash-flows/{id}/confirm` | 确认为独立流水，携带 `revision` |
| POST | `/cash-flows/{id}/link` | 关联手工记录，携带双方 ID 与版本 |
| POST | `/cash-flows/sync` | 读取渠道流水并原子去重写入 |
