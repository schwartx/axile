# SINGLE-MAKER · 单边挂单

按本方或对手价下单，可撤单追价。适合不需要分时拆单的调仓；主动报价也可能剩量。

## 执行方式

按目标持仓与当前持仓的差量下单，不做定时切片。目标已到位时无需下单。
`PASSIVE` 买单挂买一、卖单挂卖一；`ACTIVE` 买单取卖一、卖单取买一。
名称中的 MAKER 不代表始终以 maker 成交，也不保证 maker 费率。

适合不需要分时拆单的常规调仓。盘口无效时按 `on_missing_book` 处理：默认跳过该品种；
`active` 仅为兼容旧配置，盘口无效时同样阻断，不再自动转为市价单；
`market` 才会请求市价单，成交价格不受限价保护，可能产生较大滑点；是否支持取决于渠道、品种和时段，且仍须通过行情新鲜度等安全校验。

## 参数

| 参数 | 默认值 | 约束 | 说明 |
|---|---|---|---|
| `price_strategy` | `"ACTIVE"` | PASSIVE / ACTIVE | 本方挂单等成交；对手价优先成交并承担点差。 |
| `max_wait_seconds` | `60` | ≥1，≤3600 | 本轮等待成交的上限，不保证到时完成。 |
| `on_missing_book` | `"skip"` | skip / active / market | 盘口无效时跳过；`active` 兼容旧配置且同样跳过；`market` 请求市价单，有滑点风险。 |
| `chase_enabled` | `false` | 见说明 | 开启后按条件撤单追价；关闭时保留下面的追单配置。 |
| `chase_ticks` | `1` | ≥0 | 触发追价的价格偏离，不是每次加价幅度。开启追单后生效。 |
| `max_chase_count` | `5` | ≥0 | 单笔委托最多追价次数。开启追单后生效。 |
| `chase_interval` | `5.0` | ≥0.0 | 两次追价的最小间隔。开启追单后生效。 |


追单关闭时仍可配置阈值、次数和间隔；关闭不会清除这些值。开启后：偏离须为 1–100 跳，
次数为 1–50，间隔为 0.1–300 秒；次数×间隔不得超过 600 秒，间隔小于 1 秒时次数不得超过 10。
这些约束不代表算法必定持续相同时间。

当前追价使用最新本方最优价（买单买一、卖单卖一），并先确认旧单已撤，再按剩余量重挂。
撤单未确认时不重复挂新单。它不是每次机械加减若干跳，也没有“超时必转市价”的保证。

## 例子

```python
algorithm = {
    "method": "SINGLE-MAKER",
    "params": {
        "price_strategy": "PASSIVE",
        "max_wait_seconds": 60,
        "on_missing_book": "skip",
        "chase_enabled": True,
        "chase_ticks": 1,
        "max_chase_count": 5,
        "chase_interval": 5,
    },
}
```

目标 100、当前 40，先按 60 的差量挂单；达到偏离条件后可追价，每次间隔至少 5 秒，最多 5 次。
等待上限与追价条件分别控制等待和换单，不承诺完成全部 60。

## 结束与剩量

等待结束后重新读取账户资产。成交、未成交委托和剩量应结合执行结果核对；
不能把等待结束理解成全部成交或所有委托已撤。最小下单量、行情和渠道拒单都可能留下差额。
